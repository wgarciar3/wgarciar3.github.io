Networks Security GT

A cybersecurity educational project documenting research, labs and tooling from a Master's degree in Information Security at Universidad Mariano Gálvez de Guatemala.

$ whoami → security researcher · network engineer · GT

// areas of study

What this project covers

[01] Network Security

Designing and hardening segmented networks, firewall policy, VLAN isolation and traffic inspection across multi-site infrastructure.

[02] Penetration Testing

Controlled exploitation labs against vulnerable targets, service enumeration, and post-exploitation in isolated GNS3 environments.

[03] Traffic Analysis

Packet capture, protocol dissection and detection of anomalous behavior using Wireshark and command-line capture tools.

[04] Risk Management

Threat modeling and risk matrices following the ISO/IEC 27005 methodology for structured information-security assessment.

[05] Vulnerability Scanning

Authenticated and unauthenticated scans, CVE triage and remediation prioritization across test systems.

[06] Credential Security

Password strength evaluation, hashing schemes and offline cracking exercises to understand real-world attack feasibility.
